ドラレコ映像 路面状況 AI解析ツール（簡易版）

動画をブラウザ内でフレーム抽出し、指定したAI APIへ送信して路面損傷を判定します。動画自体はサーバへ送信されません（抽出画像のみAPIへ送信）。

1. 動画の読み込み

mp4 / webm など。ブラウザが再生できる形式に限ります。
—

2. フレーム抽出設定

路面が写る下半分だけ切り出す場合に指定（例:50）
抽出済み 0 枚

3. 解析API設定（ユーザー指定）

CORS許可のあるAPI、または自組織のプロキシURLを指定してください。
Anthropic系は ヘッダ名 x-api-key／値 {KEY}
汎用カスタム用テンプレート設定を開く
利用可能な差し込み変数：{MODEL} {PROMPT} {IMAGE_B64}（base64のみ） {IMAGE_DATAURL}（data:image/jpeg;base64,…）
ドット区切り。例：content.0.text（Anthropic） / result.text / 空欄なら応答全体を文字列化

4. 位置情報の突き合わせ（任意）

CSVは1行目ヘッダ可。GPXは trkpt の time を先頭点=0秒として換算します。
未読込
指定するとGPXの絶対時刻と正確に対応付けます。

5. 解析結果

解析済 0 件 要対応(A/B) 0 件 エラー 0 件
時刻画像 重大度損傷種別 確信度所見 緯度経度
